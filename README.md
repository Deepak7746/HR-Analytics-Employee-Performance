HR Analytics and Employee Performance Analysis

Project Overview
This project focuses on analyzing employee data to understand workforce trends, employee performance, job satisfaction, and attrition patterns. Python is used for data analysis, and Power BI is used for data visualization and dashboard reporting.

Objectives
- Analyze employee performance and productivity.
- Explore employee attrition patterns.
- Examine salary, job satisfaction, and training-related factors.
- Identify workforce trends through data analysis.
- Present insights using interactive dashboards.

Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
- Microsoft Power BI
- CSV Dataset

Project Workflow
1. Load the HR dataset.
2. Clean and prepare the data.
3. Perform Exploratory Data Analysis (EDA).
4. Analyze employee performance and attrition.
5. Visualize findings using charts.
6. Present key insights through a Power BI dashboard.

Project Files
- Python Notebook: Data cleaning and analysis.
- Dataset: HR employee data.
- Power BI Dashboard: HR analytics visualizations.

Key Skills
Data Analysis, Data Cleaning, Exploratory Data Analysis, Python, SQL (if used), Power BI, Data Visualization, Statistical Analysis, and Analytical Thinking.

How to Run
1. Download or clone this repository.
2. Install Python and the required libraries.
3. Open the Jupyter Notebook.
4. Update the dataset path if necessary.
5. Run the notebook cells in order.
6. Open the Power BI dashboard using Microsoft Power BI Desktop.

Conclusion
This project demonstrates how HR data analysis can help understand employee performance, workforce trends, and attrition patterns to support data-driven HR decisions.
